# REQUIREMENTS
This calculator must carry out the following mathematical operations:
1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exponents

An error message should also be produced when the user attempts to divide by 0

The calculator should be able to carry out operations such as:
1. 3+6
2. 3-6
3. 5x5
4. 5/8
5. 3^4
