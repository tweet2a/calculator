# README

#Calculator
A Python 3 calculator used from the Terminal, built step by step in SCCM4910.
## What it will do
Add, subtract, multiply and divide two numbers; display the result.
## How to run it
Install: python3
Run: run.sh
Enter the first number, operator (+ - * /), then second number.
The program prints Result: followed by the answer.
SCCM4910 virtual environment activation command: "source/opt/python-venv/sccm-4910/bin/activate"
## Checks
You can check the tests with check.sh, to see if the program divides, subtracts, multiplies and adds as intended. (5 checks should pass) The exit status should return 0 if the program has properly exited.
